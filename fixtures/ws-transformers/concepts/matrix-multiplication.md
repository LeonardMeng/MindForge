# Matrix Multiplication

## Description
两个矩阵相乘：结果第 i 行第 j 列的元素，是左矩阵第 i 行和右矩阵第 j 列的点积。神经网络里几乎所有的线性变换都是矩阵乘法。

## Learning Objectives
- 说出两个矩阵能相乘的形状条件，以及结果的形状。
- 手算一个 2×3 矩阵乘 3×2 矩阵的例子。
- 解释为什么矩阵乘法一般不满足交换律。
